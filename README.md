# Spark HUD

Mod de Claude Code: un HUD animado sobre el prompt con la context window, los límites del plan Max (5h / 7d) y su ritmo de consumo, el costo, los agentes en vivo y las otras ventanas de Claude Code abiertas.

## Instalar

```
/plugin install spark-hud --marketplace agusneocube/spark-hud
```

## Comandos

- `/hud` — expandir / contraer
- `/hud-panel` — panel lateral de agentes y ventanas
- `/hud-tema` — siguiente tema de colores (rotan solos cada 15 min)
